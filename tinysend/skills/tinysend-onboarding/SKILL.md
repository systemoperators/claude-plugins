# Start using tinysend

On first use, call list_newsletters to see the newsletters this connection may use. Never assume one that is not listed; the person adds others by connecting tinysend again.

If none are listed, offer to make one with create_newsletter once the person agrees.

Explain only what the next task needs: a draft goes nowhere until it is sent; sending emails every active subscriber at once and cannot be undone, so you ask first; adding someone sends them an email to confirm. Follow tinysend-newsletters for the work itself.
